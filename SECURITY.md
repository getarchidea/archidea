# Security

Please don't report security problems in public issues.

Use GitHub's private reporting instead: **Security › Report a vulnerability** on
[getarchidea/archidea](https://github.com/getarchidea/archidea/security/advisories/new). Include what's affected,
how to reproduce it and what an attacker could do. We'll answer within a few days and keep you posted until it's
fixed.

Problems inside Chromium itself are best reported to the Chromium project; we pick up their fixes with each engine
update.
